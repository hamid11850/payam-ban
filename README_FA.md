# زنگ خطر – نسخه ۱.۲

**عنوان پیشنهادی در کافه‌بازار:** زنگ خطر: هشدار پیامک و لینک

برنامه‌ای فارسی برای بررسی دستی متن پیامک‌ها و لینک‌های مشکوک با قواعد محلی و بدون اتصال اینترنت.

## امکانات
- واردکردن دستی متن یا جای‌گذاری از حافظه موقت
- تحلیل نشانه‌های فشار زمانی، تهدید، وعده جایزه و درخواست اطلاعات حساس
- بررسی ظاهری لینک‌ها: HTTP، Punycode، لینک کوتاه‌شده، IP مستقیم، user-info، درگاه غیرمعمول و فایل APK
- نمایش علت‌های مستقل و امتیاز نشانه‌ها از ۰ تا ۱۰
- رابط فارسی و راست‌چین با هویت بصری جدید

## حریم خصوصی
- برنامه مجوز اینترنت، پیامک یا مخاطبین درخواست نمی‌کند.
- متن فقط روی دستگاه تحلیل می‌شود.
- هیچ لینکی باز، resolve، دنبال یا به سرور ارسال نمی‌شود.
- استعلام بانکی یا اتصال به سامانه‌های بانکی وجود ندارد.

## محدودیت‌ها
- تحلیل بر اساس قواعد آفلاین است و همه کلاهبرداری‌ها را تشخیص نمی‌دهد.
- امتیاز، احتمال آماری یا اثبات کلاهبرداری نیست.
- ممکن است پیام سالم را مشکوک تشخیص دهد یا حمله جدید را تشخیص ندهد.
- HTTPS به‌تنهایی اصالت سایت را ثابت نمی‌کند.

## ساخت
Workflow فعلی در GitHub Actions خروجی Debug می‌سازد. برای انتشار در کافه‌بازار باید نسخه Release امضاشده و الزامات پنل بازار آماده شود.
