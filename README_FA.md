# پیام‌بان – نسخه ۱.۱

اپلیکیشن اندرویدی فارسی برای تحلیل دستی پیامک‌ها و لینک‌های مشکوک، با پردازش محلی و بدون اتصال اینترنت.

## امکانات
- واردکردن دستی متن یا جای‌گذاری از حافظه موقت
- تحلیل عبارت‌های فشار زمانی، تهدید، وعده جایزه و درخواست اطلاعات حساس
- بررسی ظاهری لینک‌ها: HTTP، دامنه‌های Punycode، لینک کوتاه‌شده، IP مستقیم، بخش کاربری در URL، درگاه غیرمعمول و نشانه‌های فایل APK
- نمایش دلیل‌های مستقل و امتیاز نشانه‌ها از ۰ تا ۱۰
- رابط کاربری فارسی و راست‌چین

## حریم خصوصی
- برنامه مجوز INTERNET، پیامک یا مخاطبین درخواست نمی‌کند.
- متن واردشده فقط روی دستگاه تحلیل می‌شود.
- هیچ لینکی باز، resolve، دنبال یا به سرور ارسال نمی‌شود.
- استعلام بانکی یا اتصال به سامانه‌های بانکی وجود ندارد.

## محدودیت‌های مهم
- این نسخه از قواعد آفلاین استفاده می‌کند؛ فهرست آنلاین تهدیدها یا بررسی زنده دامنه ندارد.
- امتیاز، احتمال آماری یا اثبات کلاهبرداری نیست؛ فقط وزن نشانه‌های پیدا‌شده است.
- ممکن است پیام سالم را مشکوک تشخیص دهد یا حمله جدید را تشخیص ندهد.
- HTTPS، پسوند `.ir` یا نام آشنای یک بانک به‌تنهایی اصالت سایت را ثابت نمی‌کند.
- برای کار بانکی، آدرس سایت را مستقل از پیام و از منبع رسمی بانک پیدا کنید؛ از لینک پیامک استفاده نکنید.

## ساخت APK
با هر Push به شاخه `main` یا اجرای دستی workflow با نام `Build PayamBan APK`، خروجی Debug ساخته می‌شود. Artifact با نام `payamban-v2-debug-apk` در بخش Actions قابل دریافت است.
